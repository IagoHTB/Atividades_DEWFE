Tipos de listas em HTML

Esta aplicação mostra exemplos de cada tipo de lista em páginas separadas.

Menu de navegação

  • Lista Ordenada - uma sequência numerada ou com letras.
  • Lista Não Ordenada - itens marcados com bullets.
  • Lista de Descrição - termos com definições.

Como usar

Use o menu para navegar entre os exemplos de listas ordenadas, não ordenadas e listas de descrição.
