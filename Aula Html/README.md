# Controle de Salas — SENAI Bauru

Projeto front-end simples para controle de salas, reservas e visualização de conflitos.

Como usar
- Abra `index.html` no navegador (duplo clique ou servidor estático).
- Use `+ Nova Sala` para adicionar salas.
- Clique em `Reservar` em uma sala para criar reservas.
- Dados são salvos no `localStorage` do navegador.

Arquivos
- index.html — interface principal
- css/styles.css — estilos
- js/app.js — lógica de aplicação

Observações
- Sistema é client-side sem backend. Para multiusuário, é necessário servidor e banco.
